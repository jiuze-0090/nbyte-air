# 留资线索接收端 · 腾讯云函数 SCF 部署说明

官网（Cloudflare Pages）提交的咨询表单，由这个函数接收并落地。

```
官网表单 ──POST──▶ SCF 函数 ──┬──▶ CloudBase 数据库（leads 集合）
                              └──▶ 企业微信群机器人（顾问手机立刻收到）
```

---

## 一、准备：企业微信群机器人（5 分钟，强烈建议先做这个）

企微是**拿到线索的主要通道**——数据库只是存档。数据库没配也不影响收线索。

1. 电脑上打开**企业微信**（不是个人微信），进「群聊」→ 新建或选一个群（建议叫「新字节航空·招生值班」）
2. 群设置 →「群机器人」→「添加机器人」→「新建机器人」→ 名字填 `新字节航空留资`
3. 复制它的 **Webhook 地址**（形如 `https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxx`）

> Webhook 地址 = 一把万能钥匙，谁拿到都能往群里发消息。**不要写进前端代码**，只放在函数的环境变量里。

## 二、建云函数

1. 登录 [腾讯云控制台](https://console.cloud.tencent.com/) → 搜「云函数 SCF」
2. 地域选**广州或上海**（离学员近）
3. 「新建」→ 名称 `nbyte-lead-handler`，运行时选 **Node.js 18.x**，内存 256MB，超时 10 秒
4. 「上传方式」选**文件夹上传**，把本目录（`index.js` + `package.json`）压缩成 zip 上传
   > 只上传本目录这两个文件，不要把 `node_modules` 一起压进去（云端会装）
5. 「高级配置 → 环境变量」加三条：

   | 变量名 | 值 |
   |---|---|
   | `CORS_ORIGINS` | `https://www.nbyteair.com`（实验室要用就补 `,https://lab.nbyteair.com`） |
   | `WECOM_WEBHOOK` | 第一步复制的 Webhook 地址 |
   | `LEAD_COLLECTION` | `leads`（可改） |

6. 「触发管理」→ 新建 **API 网关触发器**（或「HTTP 访问服务」），路径随意（如 `/lead`），启用后
   **公网访问权限设为「公网访问」**，拿到形如 `https://xxx.ap-shanghai.scf.tencent.com/api/xxx` 的地址

## 三、（可选）建 CloudBase 集合

想留历史线索、可查可导出，就建 CloudBase：

1. 腾讯云控制台 → 云开发 CloudBase → 新建环境（和云函数同地域最好）
2. 「数据库」→ 新建集合 `leads`
3. 权限选「仅创建者可读写」或「所有用户可读，仅创建者可写」（前端不直连，只由函数写入）
4. 函数环境变量加 `SCF_NAMESPACE` = 你的环境 ID

没有 CloudBase 也能跑：函数会自动跳过落库，只发企微通知。

## 四、接到官网上

1. 在**官网项目根目录**新建 `.env.local`：

   ```
   VITE_LEAD_ENDPOINT=https://xxx.ap-shanghai.scf.tencent.com/api/xxx
   ```

2. 重新构建部署：

   ```bash
   npm run build
   git add -A && git commit -m "chore: 配置留资接口地址" && git push
   ```

   > `.env.local` 不要提交到 git（已在 .gitignore 里就更好）——它只参与本地构建。
   > 生产环境每次构建都要有这个变量，否则表单会退回「复制到剪贴板」模式。

3. 打开官网提交一次表单，确认：
   - 页面提示「已收到，顾问今天内联系你」
   - 企微群收到一条带姓名/手机号的 markdown 消息
   - （建了 CloudBase 的话）`leads` 集合里多一条记录

## 五、排错

| 现象 | 原因 |
|---|---|
| 浏览器报 CORS 错误 | `CORS_ORIGINS` 没包含官网域名，或域名写法不一致（`https://` + 域名，无路径、无末尾斜杠） |
| 提示「已收到」但企微没消息 | `WECOM_WEBHOOK` 配错或机器人被移出群；先去群里确认机器人还在 |
| 提示「已收到」但数据库没记录 | 正常——说明数据库没配，函数会跳过落库只发通知 |
| 提交后一直转圈 | 函数没给 API 网关开公网访问，或超时太短 |
| 频繁收到同一 IP | 限流是 60 秒 3 次；可调 `RATE_LIMIT_MAX` |

## 六、字段与隐私

- 函数日志里手机号已脱敏（`138****0090`），完整号码只写进数据库
- 收集的是手机号 + 称呼 + 意向课程，官网表单下方应有一句用途说明：
  「仅用于课程咨询联系，不对外提供」——**这句必须加**（《个人信息保护法》要求告知用途）
