# 官网内容硬约束（对外口径）

> **这份文档是改官网内容前必须先读的口径红线。**
> 面向：任何 AI 助手、开发者、运营人员。
> 上次核对：2026-11-24（对照 `src/data.ts`、`src/components/*.tsx`、`index.html` 三处实现）
>
> 违反其中任何一条，对外内容就可能出现虚假宣传或资质表述违规——这不是风格问题，是法律风险。

---

## 1. 学费、开班日期、学制：禁止编造数字

**现状**：这三个值在 `src/data.ts` 的 `courseFacts` 里是**空字符串**，页面自动降级显示「详询招生顾问」。

```ts
// src/data.ts · courseFacts
{ icon: CalendarDays, label: '开班日期', value: '' },
{ icon: Clock, label: '学制（理论 + 实操）', value: '' },
{ icon: Coins, label: '学费', value: '' },
```

**规则**：

| 允许 | 禁止 |
|---|---|
| 留空，由页面显示「详询招生顾问」 | 填入任何未确认的价格、日期、天数 |
| 用户明确给出真实数据后，填进 `value` | 从别处（同行报价、历史版本、其他机构）推算或"参考"一个数字 |
| 描述课程结构（模块、时长区间的定性描述） | 用"约""起""低至"等模糊词包装编造数字 |

**为什么**：官网是成交中枢。学费一旦写错即为虚假宣传，且招生报价随班型/人数变动，写死必然失准。

**填值的正确姿势**：拿到真实数据 → 只改 `courseFacts` 的 `value` → 不要动组件结构。

## 2. 资质口径：只能这样说

### 2.1 唯一允许的机构称谓

> **「无人机驾驶员执照培训与实训基地」**

**禁止**使用：

- ❌「培训机构」
- ❌「训练机构」
- ❌「CAAC 培训基地」
- ❌「民航局授权培训机构」（指称自己）
- ❌「考证推荐」（无推荐资格）

> **注意区分**：文案里出现「民航局授权培训机构」是**合法且必须保留**的——它指的是
> *负责受理考试报名与学籍登记的第三方有证机构*，不是指称本机构。
> 现有实现见 `src/data.ts` FAQ 与 `src/components/Stats.tsx`：
> 「报名受理与学籍登记**由民航局授权培训机构统一办理**；本机构承担全部理论与实操教学」。

### 2.2 资质编号：唯一正确值

```
UAOC-O-HQ-20250507079
```

- 名称：《民用无人驾驶航空器运营合格证》
- 经营种类：载货类、培训类
- 有效期：2025-05 ~ 2027-05
- 查询渠道：民航局 UOM 平台 `uom.caac.gov.cn`

**编号读法**（避免再写错）：

| 段位 | 含义 | 本机构 |
|---|---|---|
| `UAOC` | Air Operator Certificate，运营合格证统一前缀 | 固定 UAOC |
| 第 2 位 | `O`=开放类 `S`=特定类 `C`=审定类 | **O**（开放类） |
| `HQ` | 发证机构代码，HQ = 民航总局 | HQ |
| `20250507079` | 发证日期 + 当日序列号 | 2025-05-07 第 079 号 |

**已发现的错误写法**（历史记忆里出现过，勿再犯）：

- ❌ `UMOC-0-HQ-20250507079` —— `UMOC` 前缀错（无此缩写）、`0` 应为字母 `O`
- ✅ `UAOC-O-HQ-20250507079`

当前代码 3 处均为正确值：`src/data.ts`（FAQ 第 2 条）、`src/components/Stats.tsx`、
`index.html` 的 meta description / JSON-LD / 静态正文。

### 2.3 资质编号要主动报出来

不要只写「持证运营」这种形容词。**直接把编号写出来**——学员和渠道方能自己去 UOM 查，
比任何形容词都有说服力。这是硬要求，不是可选项。

### 2.4 责任边界必须讲清

官网已定稿的三段式表述（保持不变）：

1. 执照由**民航局**颁发
2. 报名受理与学籍登记**由民航局授权培训机构统一办理**
3. **本机构承担全部理论教学、真机实操与考前辅导**

不得暗示"包过""免考""内部名额""绿色通道"。报考条件与考试规则，以民航局及当地民航地区管理局最新公布为准。

### 2.5 场地用词

- ✅「实训基地」「潍坊奎文实训基地」「新字节航空实训基地」
- ❌「培训基地」（与「培训机构」同类受管制称谓）

## 3. ICP 备案号：留空，不显示

**现状**：`src/components/Footer.tsx`

```ts
const ICP_NUMBER = '';   // 备案下来后把工信部下发的号填进这里即可自动显示
```

```tsx
{ICP_NUMBER && (   // 空值时整块不渲染
  <p><a href="https://beian.miit.gov.cn" ...>{ICP_NUMBER}</a></p>
)}
```

**规则**：

- 备案完成前 `ICP_NUMBER` 保持 `''`，页面**不显示任何备案号占位文案**（不要写"备案中"之类的假号）
- 备案下来后填入**工信部下发的网站备案号**，形如 `鲁ICP备XXXXXXXX号-1`
- 一个主体只有**一个主体备案号**（`鲁ICP备XXXX号`）；备案只针对一级域名，
  `www.` / `lab.` 属子域名，**不单独备案、也拿不到独立号**，两个子域挂同一个网站备案号
- **必须挂带 `-N` 后缀的网站备案号**，不能只挂主体号
- 前提：`www` 与 `lab` 两个子域指向**同一接入商**的境内节点

> 属地备注：本机构主体在山东潍坊（鲁）。

## 5. 改动官网前后的自检清单

改完 `src/data.ts`、`src/components/*.tsx` 或 `index.html` 后，逐条过一遍：

- [ ] 有没有新增任何学费 / 学制 / 开班日期的具体数字？
- [ ] 有没有出现「培训机构」「训练机构」「培训基地」「CAAC 培训基地」？（描述第三方有证机构时不受限）
- [ ] 资质编号是不是 `UAOC-O-HQ-20250507079`？（`UAOC` + 字母 `O`）
- [ ] 资质编号有没有主动写出来，而不是只写「持证运营」？
- [ ] 报名/学籍登记的责任方有没有写成「由民航局授权培训机构统一办理」？
- [ ] 有没有暗示包过、免考、内部名额？
- [ ] `ICP_NUMBER` 仍是 `''`（备案未完成时）？
- [ ] 改的是 `index.html` 的话，JSON-LD 里的 FAQ 与正文是否同步改了？（三处：`src/data.ts` / `index.html` meta+JSON-LD / 组件）
- [ ] 构建通过：`npm run typecheck && npm run build`
